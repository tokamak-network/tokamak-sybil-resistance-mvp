# Usage

## Verifier Contract Generation

To generate a Solidity verifier contract for your circuits, follow these steps:

1. Install dependencies:
~~~bash
npm install
~~~

2. Generate the verifier contract:
~~~bash
npm run verifier
~~~

This will generate Solidity verifier contracts for all circuits defined in `circuits.json`. The generated contracts will be saved in the `verifiers/` directory with the naming pattern `{CircuitName}Verifier.sol`.

For example:
- `verifiers/BatchMainVerifier.sol`
- `verifiers/ProveScoreInclusionVerifier.sol`

These Solidity smart contracts can verify proofs generated by your circuits.

If you want to generate a circuit with different parameters, you should modify the [circuits.json](circuits.json) file.
